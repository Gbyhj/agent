# SLOs — Service Level Objectives

> 参考: Google SRE · 定义什么是"正常运行"

## API 服务级别

| 指标 | 目标 (SLO) | 测量方式 |
|------|:--:|------|
| **可用性** | 99.5% (月) | /api/health 返回 200 的比例 |
| **延迟 (p50)** | < 1s | /api/chat 端到端响应时间 |
| **延迟 (p95)** | < 5s | 同上 |
| **延迟 (p99)** | < 15s | 同上 |
| **错误率** | < 1% | 4xx/5xx 占总请求的比例 |
| **Token 效率** | < 2000 tokens/task | 每任务平均 Token 消耗 |

## Agent 质量指标

| 指标 | 目标 | 测量方式 |
|------|:--:|------|
| **任务完成率** | > 85% | Agent 返回 final_answer 的比例 |
| **工具准确率** | > 90% | 选择的工具是否正确（benchmark）|
| **反射命中率** | > 70% (10 任务后) | 条件反射匹配成功的比例 |
| **审查通过率** | > 80% | 对抗审查 critical=0 的比例 |
| **记忆召回率** | > 90% | ChromaDB 语义搜索准确率 |

## C 端指标

| 指标 | 目标 | 测量方式 |
|------|:--:|------|
| **日活用户** | 跟踪增长 | 每天有请求的 user_id 数 |
| **用户满意度** | > 4.0/5.0 | 👍👎 反馈 |
| **首次任务成功率** | > 70% | 新用户第一次任务完成的比例 |

## 告警规则

| 条件 | 级别 | 动作 |
|------|:--:|------|
| 可用性 < 99% (1h 窗口) | P1 | 立即通知 |
| p95 延迟 > 10s (10min) | P2 | 通知 + 降级 |
| 错误率 > 5% (5min) | P1 | 立即通知 |
| Token 消耗异常飙升 | P2 | 通知 + 限流 |

## 月度总结

每月生成 SLO 报告：达标率、趋势图、改进项。
